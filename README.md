# Wake-Up Call — 酒馆「定时提醒 / 叫醒」插件

适用于 SillyTavern（Termux 本地部署，sillydroid）的一套提醒自动化：

- **任意时间**：「十五分钟后提醒我」「半小时后」「明天 7 点叫醒我」「下午 3 点半」「晚上 10 点」都支持；
- **晚安默认**：说「晚安/睡了」→ 默认时间（默认 08:00）提醒；
- **可取消**：说「取消提醒/取消闹钟」即可取消；到点通知也可点击取消；
- 到点后（**全程不打开酒馆**）：手机**普通通知弹窗**显示角色用 AI 生成的「早安」回复（调一次 API）；
- 酒馆聊天记录里会附加一条系统消息「已醒来」，带 `is_system` 标志：**显示但不进入 AI 生成上下文，不计入主线剧情**。

**安装即用**：酒馆填地址装扩展 → Termux 跑一条部署命令 → 设置面板填 API 配置 → 完事。不用改任何脚本文件。

---

## 安装（三步）

### 第 1 步 · 酒馆里安装扩展

酒馆 → 右侧扩展面板 → **Install extension** → 粘贴本仓库地址：

```
https://github.com/luobo1002/wake-up-call
```

（需手机 Termux 里装过 `git`；装完重启酒馆。）扩展设置出现在右侧「扩展」面板，名为 **Wake-Up Call**。

### 第 2 步 · Termux 里跑一条命令

打开 Termux（不用 cd，命令里的路径是固定的）：

```bash
bash ~/SillyTavern/data/default-user/extensions/wake-up-call/setup.sh
```

> 如果你的酒馆目录不叫 `SillyTavern`，或用户名不是 `default-user`，把命令里的路径换成实际的（`ls ~/SillyTavern/data/` 可看）。

这条命令自动完成：复制桥/生成/定时脚本到 `~/bin/`、`~/morning.py`、`~/.shortcuts/`，加执行权限，生成默认配置 `~/wakeup_config.json`，并启动桥服务（已运行则跳过）。

### 第 3 步 · 酒馆设置面板填 API 配置

打开酒馆 → 扩展 → Wake-Up Call 设置：

1. 在「AI API 配置」里填 **API 地址 / 模型名 / API Key**（和你酒馆里用同一个服务商即可）；
2. 点**保存设置** —— 配置会自动同步到 Termux（写入 `~/wakeup_config.json`，`morning.py` 直接读取，**不用改任何脚本**）。

设置面板顶部会显示「部署状态」：桥已连接 = 绿色，未连接 = 红色（说明第 2 步没跑或桥没起来）。

## 运行流程（完整版：全程不打开酒馆）

```
前一天晚上 你在酒馆聊天里发"晚安" / "明天7点叫醒我" / "十五分钟后提醒我"
        │
        ▼
酒馆扩展 Wake-Up Call（index.js）
        ├── 解析目标时间（相对时间 / 绝对时间 / 晚安默认 / 取消指令）
        ├── 把【角色人格 + 最近聊天记录】POST 给 Termux 桥（/cache）→ 存到 ~/wakeup_cache.json
        └── 调 Termux 桥（/schedule 或 /cancel）
                                        │
                                        ▼
                        Termux 桥 bridge.py（127.0.0.1:8765）
                        └── termux-job-scheduler      → 注册一次性后台任务
                                                            │ 到点
                                                            ▼
                                                wake_job.sh（酒馆网页全程不参与）
                                                    ├── python3 ~/morning.py
                                                    │      └── 读角色缓存 + 配置里的 API
                                                    │            生成角色"早安"回复
                                                    └── termux-notification 普通通知弹窗
                                                          （标题=角色名，内容=角色的话，
                                                           声音+震动，点击可取消）
```

**关键点：到点后酒馆网页（浏览器）完全不用打开**——通知是 Termux 系统通知，角色回复由 Termux 直接调 AI API 生成。酒馆只需要在前一天晚上被打开过一次（说晚安/设提醒），之后可以完全关掉。

## API 配置

**不用改任何脚本文件**，全部在酒馆扩展设置面板里填：

| 项 | 示例 | 说明 |
|---|---|---|
| API 地址 | `https://api.openai.com/v1` | OpenAI 兼容服务商地址 |
| 模型名 | `gpt-4o-mini` | 你的模型名 |
| API Key | `sk-...` | 你的 Key |

保存后自动写入 Termux 的 `~/wakeup_config.json`，`morning.py` 启动时读取。

常见 OpenAI 兼容服务商（**和你在酒馆里用的同一个服务商即可**）：

| 服务商 | api_base | 示例模型 |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | 填你的模型名 |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 本地 Ollama（可选） | `http://127.0.0.1:11434/v1` | `qwen2.5` 等 |

> 如果你的服务商不是 OpenAI 兼容格式（如 Anthropic Claude 原生接口），需要在 `~/morning.py` 里把 `call_api` 改成对应格式。

## 不打开酒馆也能被提醒（重点）

到点提醒你的东西**不依赖酒馆**，酒馆关着也一样生效：

- **普通通知弹窗**：`wake_job.sh` 里的 `termux-notification` 弹出高优先级通知横幅（声音+震动），内容就是角色生成的早安回复；
- 默认**不调系统闹钟**（`bridge.py` 里 `ALARM_ENABLED = False`）；如果你想要系统闹钟响铃，把它改成 `True` 即可（注意部分 ROM 会弹新建闹钟界面需手动确认）。

酒馆里那条"已醒来"系统消息只是附加项——酒馆没打开时，它会被写入聊天记录，下次打开酒馆即可看到，不影响提醒本身。**如果你完全不想要酒馆消息**，把 `~/bin/wake_job.sh` 里的 `curl` 那几行注释掉即可。

## 独立弹窗设提醒（完全绕开酒馆）

如果连"设提醒"都不想打开酒馆，用 `~/.shortcuts/wake_dialog.sh`（setup.sh 已自动部署）：

```bash
pkg install termux-api termux-widget
```

然后**长按手机桌面 → 添加小部件 → Termux:Widget → 选 wake_dialog**，桌面上就会多一个按钮。点一下直接弹出系统时间选择器，选好时间就设好提醒，全程不碰酒馆。

## 生效范围（适配手机端使用方式）

扩展加载后默认**所有聊天都生效**——手机端任何聊天里说"晚安/明天X点"都会触发。

如果你不想主线剧情聊天被误触发，可以在扩展设置里改「生效范围」：

| 模式 | 适用场景 | 说明 |
|---|---|---|
| 所有聊天都生效 | 手机平时聊天直接用 | 任何角色聊天里说"晚安"都会设提醒 |
| 仅指定角色聊天生效 | **新开一个"闹钟管家"聊天专用** | 在设置里填角色名白名单（逗号分隔），只有这些聊天里说"晚安"才触发；主线剧情里说"晚安"完全不触发 |
| 停用 | 临时关闭 | 完全关闭叫醒功能 |

> 角色名 = 你新建聊天时用的角色卡片名字，白名单填角色名即可（如 `闹钟管家`）。

## 文件说明

| 文件（扩展目录内） | 部署后位置 | 作用 |
|---|---|---|
| `manifest.json` / `index.js` / `settings.html` | 酒馆扩展目录 | 前端扩展（不用动） |
| `setup.sh` | 扩展目录内 | **一键部署脚本**（Termux 跑一次） |
| `bridge.py` | `~/bin/wake_bridge.py` | 本地 HTTP 桥：设定/取消提醒 + 接收角色缓存 + 配置同步 |
| `morning.py` | `~/morning.py` | 读角色缓存 + 配置 → 调 AI API 生成角色早安回复 |
| `wake_job.sh` | `~/bin/wake_job.sh` | 到点执行：弹普通通知显示角色回复（+可选酒馆记录） |
| `wake_cancel.sh` | `~/bin/wake_cancel.sh` | 取消提醒（通知点击 / 手动执行） |
| `wake_dialog.sh` | `~/.shortcuts/wake_dialog.sh` | 桌面快捷方式弹窗，不打开酒馆直接设提醒 |

配置文件（部署后自动生成）：`~/wakeup_config.json`（密钥 + API 配置，酒馆设置面板保存时自动同步）；`~/wakeup_cache.json`（角色缓存）；`~/wake_bridge.log`（桥日志）。

## 支持的说法

| 你在聊天里说 | 效果 |
|---|---|
| 晚安 / 睡了 / 睡觉 | 默认时间（默认 08:00）提醒 + 缓存角色 |
| 明天 7 点叫醒我 / 明天7点叫我 | 明天 07:00 提醒 + 缓存角色 |
| 明天 7:30 叫我 / 明天七点半叫我 | 明天 07:30 提醒 + 缓存角色 |
| 明天 7点15分叫我 | 明天 07:15 提醒 + 缓存角色 |
| 十五分钟后提醒我 | 15 分钟后提醒 + 缓存角色 |
| 半小时后叫我 | 30 分钟后提醒 |
| 2 小时后提醒我 | 120 分钟后提醒 |
| 下午 3 点半叫我 | 当天 15:30（已过则顺延一天） |
| 晚上 10 点提醒我 | 当天 22:00 |
| 15:30 叫我 | 当天 15:30（已过则顺延一天） |
| 取消提醒 / 取消闹钟 | 取消已设定的提醒 |

到点后：**普通通知弹窗显示角色生成的早安回复**（调用你配置的 AI API，角色人格和最近聊天取自晚上缓存的 `~/wakeup_cache.json`）；点击通知可取消；酒馆聊天记录附加系统消息（可选）。

## 注意事项 / 已知限制

1. **提醒方式**：默认只用**普通通知弹窗**（`ALARM_ENABLED = False`），简单可靠。想要系统闹钟响铃，把 `~/bin/wake_bridge.py` 里 `ALARM_ENABLED` 改成 `True`（注意：`am start SET_ALARM` 在部分 ROM 上会弹出新建闹钟界面，需手动点一次保存）。
2. **不计入主线**：注入消息 `is_system: true`，SillyTavern 默认不把它放入 AI 生成上下文，角色不会因此自动回复，剧情不受影响。若你希望它被 AI 感知（进上下文），把 `index.js` 里 `injectSystem` 的 `is_system: true` 改为 `false` 即可。
3. **安全**：扩展端点和桥都只监听 `127.0.0.1`。**不要**给 SillyTavern 加 `--listen` 暴露到公网（否则 `/api/wake-up` 无公网防护）。
4. **定时可靠性**：依赖 Termux 进程存活。给 Termux 开「后台运行」+ **关闭电池优化**，并执行 `termux-wake-lock`；Termux 被彻底划掉/重启后，重新跑一次 `setup.sh`（会幂等重启桥）。
5. **"明天"语义**：扩展把「明天 X 点」算成下一个自然日；若该时刻已过（如凌晨说"明天 7 点"），会再顺延一天。
6. **API 费用与失败兜底**：`morning.py` 每次到点会调一次 AI API（按你的服务商计费）。API 调用失败或未配置时，弹窗会显示兜底文案，**提醒本身不受影响**。

## 排障

| 现象 | 排查 |
|---|---|
| 发晚安后聊天里没有确认消息 | 看酒馆浏览器控制台（F12）有无 `[WakeUp]` 报错；确认扩展已加载（扩展面板可见设置） |
| 设置面板状态显示「桥未连接」 | 第 2 步没跑或桥没起来：在 Termux 跑 `bash ~/SillyTavern/data/default-user/extensions/wake-up-call/setup.sh` 重试；看 `~/wake_bridge.log` |
| 确认消息出现但手机没提醒 | 确认桥在运行（手动测：`curl "http://127.0.0.1:8765/schedule?key=wake-2026&ts=$(( $(date +%s) * 1000 + 60000 ))"`）；看 `~/wake_bridge.log` |
| 设错了想取消 | 聊天里说「取消提醒」；或 `~/bin/wake_cancel.sh`；或点弹窗通知 |
| 到点没弹窗 | 确认 Termux 没被系统杀后台；手动执行 `~/bin/wake_job.sh` 测试；确认设置面板里 API 配置已保存 |
| 弹窗出现了但内容是"生成失败/请先配置" | 设置面板里 API 配置没保存或填错；先在 Termux 手动跑 `python3 ~/morning.py` 看报错 |
| 弹窗内容是通用问候、不像角色 | 角色缓存没写入（`~/wakeup_cache.json` 不存在）——说明说晚安时桥没在运行或密钥不一致，扩展没法 POST /cache |
| 到点有弹窗但酒馆记录没写入 | `wake_job.sh` 里 `API_URL` 端口与酒馆实际端口不一致（不想要酒馆记录就直接注释掉 curl 行） |
